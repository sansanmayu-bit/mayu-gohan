# だんらん勤務表メーカー

グループホームだんらん 1ユニットの月次勤務表アプリ。`kinmu-app.html` の1ファイルだけで動きます。
実際に使うのは、このファイルを Artifact として公開した限定共有ページのほうです。

スタッフが自分のスマホで希望休・有給を入力し、締切後に「勤務表を作成」を押すと、
シフトのルールに沿った1か月ぶんの勤務表ができあがります。
色分け・合計時間・ルール違反のチェックまでその場で出るので、
気になるマスは押して直し、そのままスプレッドシートに貼り付けられます。

## 画面

| タブ | できること |
|---|---|
| 希望を出す | 名前を選んでカレンダーの日をタップ（希望休 → 有給 → 夜勤NG → 出勤希望 → 取消） |
| 提出状況 | 誰が出したか／日ごとの希望休の重なり／未提出者の声かけ文をコピー |
| 勤務表 | 自動作成・マスの手直し・要チェック一覧・スプレッドシート用コピー・印刷 |
| 設定 | 対象月、目標時間、必要人数、スタッフ名簿、シフトの実働時間、控えの書き出し |

## 自動作成のしくみ

1. 「曜日固定」のスタッフに曜日パターンを当てる（`/` 区切りで週替わりの繰り返しにも対応）
2. 希望休・有給を上書きで反映する
3. 前月末が夜勤なら1日を「明」にする
4. 夜勤を1日ずつ埋める（夜勤の翌日は必ず「明」、回数と目標時間で均す）
5. 早番・日勤・遅番を必要人数まで埋める（目標時間に近い人から順に）
6. 常勤の合計時間を目標に寄せる（超過分を削り、不足分を日勤とF系で足す）
7. ルール違反を洗い出して「要チェック」に並べる

祝日は1980〜2099年ぶんを内蔵の計算式で判定します（春分・秋分・振替休日・国民の休日を含む）。

## 名簿のまとめて登録

設定タブのテキストエリアに1行1人で貼り付けます。4つ目以降は省略できます。

```
氏名,雇用形態,ルール,曜日パターン,夜勤,目標時間
```

- 雇用形態 … `常勤` / `パート`
- ルール … `基準`（この人の合計が全員の目標）/ `自動` / `曜日固定` / `空白`
- 曜日パターン … `月:D;火:休;木:休/日/F4` のように `;` で区切る。`/` は1週目・2週目…の繰り返し。`祝:休` も指定できる
- 夜勤 … `夜勤可` / `夜勤不可`
- 目標時間 … パートに個別の目標を持たせたいときだけ

## データの置きどころ

名簿・希望・勤務表はすべて Artifact のページ自身に保存されます
（「送信」「保存して共有」を押すとページの新しいバージョンとして発行され、開いている全員に届きます）。
共有につながっていないときは、その端末の localStorage にだけ残ります。
**個人情報はこのリポジトリには置きません。** スタッフの氏名はアプリを開いてから登録してください。

## 公開サイトとの関係

このサイトは Cloudflare Pages で配信されているため Jekyll は動きません。
`_` 始まりのフォルダも配信対象から自動では外れないので、このフォルダのファイルは
パスを直接叩けば読めます。ただし置いているのはソースだけで、
**氏名・希望・勤務表といった中身は1バイトも含みません**（すべてアプリを開いてから登録します）。
実際にプレビュー環境で確認したところ、
`/_kinmu/` は（存在しないパスとして）トップへ飛ばされる一方、
`/_kinmu/kinmu-app.html` はアプリとして開いてしまいました。
共有につながっていない見本が開くとスタッフの入力が誰にも届かないため、
リポジトリ直下の `_redirects` で `/_kinmu/*` をトップへ 302 で戻しています。

## 開発メモ

- `kinmu-app.html` は Artifact 公開用のソースなので `<!doctype>` / `<html>` / `<head>` / `<body>` を持ちません（公開時に付きます）。
- 更新するときは、同じ Artifact に上書き公開してください（別のURLを作らないよう、公開済みのURLを指定します）。
- ページは読み込み時に `document.body.innerHTML` を控えておき、保存時は状態のJSONだけ差し替えて
  完全なHTMLを組み立て直して `claude.use("artifact").publish()` に渡します。
  そのため **`<script>` は必ずファイルの最後**に置いてください。
- 状態は `<script type="application/json" id="app-state">` に埋め込まれます。
